# Evidence before recovery integration

`tasks.json` records the eight declarations before opt-in memory and transport
were wired into the adapter. Gates, budgets, architectures and stream laws are
unchanged by that integration; dependency and adapter source fingerprints change.

The archive contains byte-identical copies of 72 strict-online receipts and their
72 actual-training GIFs: the initial three recipes, two newly measured baselines,
and four optimizer ablations. Relative GIF links inside receipts resolve within
this directory. Canonical paths may subsequently receive fresh source-bound runs.

`manifest.json` protects these 144 archive files and the 112 original historical
receipt/GIF files still at their canonical paths. It is a hash inventory, not a
second leaderboard. Current qualification is generated only in
`reports/forge/technique-inventory.md`.
